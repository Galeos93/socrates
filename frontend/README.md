## Quick Start

### Prerequisites

- Node.js

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Set up environment variables:
   ```bash
   # Set the GEMINI_API_KEY in .env.local to your Gemini API key
   ```

### Running the Application

Run the app:
```bash
npm run dev
```
